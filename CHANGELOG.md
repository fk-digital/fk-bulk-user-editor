## [0.0.1] - 2026-11-03

### Added

- "Add to Sites…" bulk action on Network Admin › Users.
- Screen for choosing the role and the sites, with "Select all".
- Option to change the role of users who are already members of a site. Off by default, so existing members are skipped.
- Bulk-action checkbox for super admins on Network Admin › Users.
- Summary notice showing memberships added, changed, skipped and failed.
- Activation check that blocks the plugin on single-site installs.
- Translation support (`fk-bulk-user-editor` text domain).
